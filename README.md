## About me

I'm a developer focused on **agentic AI, developer tooling, terminal interfaces, and open-source infrastructure**.

Most of my work explores a simple question:

> How can we make software agents faster, more capable, and genuinely useful inside real development workflows?

Currently, I am:

- Building local-first memory and context systems for coding agents
- Contributing to open-source coding-agent infrastructure
- Exploring terminal automation, tool use, persistent context, and agent coordination
- Working with Go, TypeScript, Python, and shell tooling
